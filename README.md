# صانع الشورت (ShortsMaker)

تطبيق أندرويد شخصي يحوّل أي جزء من فيديو عرضي إلى شورت عمودي 9:16: الفيديو كامل بالنص بدون قص، والخلفية نسخة مكبّرة مغبّشة منه.

- شريط زمني بصور مصغّرة وتعديل بدقة الإطار، ومدد جاهزة لين 3 دقايق
- معاينة حيّة بنفس شكل التصدير (غباش، تغميق، حجم، موضع، زوايا، ظل)
- البحث الذكي عن أفضل اللقطات بدون إنترنت (الصوت + الحركة + تغيّر المشاهد)
- تصدير أكثر من شورت مرة وحدة إلى Movies/ShortsMaker

الـ APK يطلع تلقائيًا في Releases باسم `apk-latest` بعد كل دفع.
